# План задач — 2026-07-09

Составлен с Димой после первого захода в редактор с паком 3D Road Tiles.
Приоритет: **T1 (коллизии) критичен**, из T2 (палитра) — минимум большие картинки.

## T1. КРИТИЧНО: физика/коллизии road-tiles (110 из 302 тайлов = approx-flat)

**Симптомы (скрины Димы 2026-07-09):** (a) заехал внутрь борта water-канала;
(b) невидимая стена на заезде в гору при явном проезде.

**Root cause (подтверждён каталогом):** `roadTilesCatalog.json` держит для
`slope-curved` (36), `slope-diagonal` (14), `water` (27), `bridge` (15), `misc` (18)
физику `approx` = «плоский на topMedian». topMedian у тайлов со стенками/бортами —
высота СТЕНОК → ступень >MAX_STEP на границе = невидимая стена (фото 3); борта
каналов не имеют стен по контуру → проникание (фото 2). Нарушение правила
`feedback_collision_contour_feel` (коллизии строго по видимому контуру).

**Фикс — суб-клеточный heightfield (грид вместо plane-fit):**
1. **Диагностика-репро**: собрать мини-карту из тайлов с фото Димы (water-канал +
   его склон), прогнать `tools/scan_heightfield.mjs`, зафиксировать текущее поведение.
2. **bake-road-tiles.mjs**: колоночный сэмплинг 24×24 уже есть — дополнительно
   сохранять в каталог height-GRID per tile (даунсемпл до 12×12, ~300KB JSON на 302
   тайла). Плоские/прямые склоны могут остаться компактной exact-записью.
3. **Runtime Heightfield**: для тайлов с гридом сэмплировать высоту внутри клетки
   по гриду (bilinear или point). MAX_STEP wall-check при мелком шаге сам даёт
   стены точно по контуру (борта каналов, стенки склонов) — отдельных SAT-стен
   не нужно.
4. **Вода**: семантика на первый заход — твёрдое «дно» на уровне поверхности воды
   (ездабельно), борта — честные стены из грида. Тонуть/замедляться — потом.
5. **Регрессия**: диаг-карта из проблемных тайлов + тесты рядом с
   `heightfieldRoadTiles.test.ts`; прогнать по карте Димы (map_v2 / его текущая).
6. **НЕ в этот заход**: проезд ПОД мостами — колоночная модель не умеет слои,
   отдельная задача (мультислойный heightfield), мосты пока approx.

## T2. Палитра 300+ тайлов — UX

1. **(минимум, делаем)** Модалка-браузер ассетов с БОЛЬШИМИ картинками:
   отдельное окно (кнопка + hotkey), грид крупных превью (тумбы уже рендерятся
   96px — показывать их крупно, а не 40px), фильтр по категориям + текстовый поиск,
   клик = выбрать ассет и закрыть. Поиск по картинке — главный сценарий Димы.
2. **(дёшево, вторым шагом)** Цветовые семейства как на Kenney-превью: в каталоге
   уже есть `materials` per tile — автогруппировка по доминирующим материалам
   (Grass/Water/Asphalt/Sand...) без ручной разметки.
3. **(потом)** Пользовательские группы деталей (избранное/наборы) — по явному
   запросу Димы, после обкатки 1-2.

## Ворота (стандарт)

Из `web-slice/`: `npx tsc --noEmit` + `npx tsc --noEmit -p server/tsconfig.json` +
`npx vitest run` — всё зелёное перед каждым коммитом. После правок `server/` —
рестарт match server (:8091), tsx не hot-reload'ит.
